# Evaluation Documentation

Store versioned agent, Skill, and RAG evaluation datasets, methods, metrics,
results, failure analysis, and remediation evidence here.

When you add Skills during the course, record the selected Skill name and
version (or no match) for each scenario. Keep selection and no-match tests,
false-trigger and missed-trigger cases, and comparisons with and without the
Skill under the same model, tools, dataset, and budget. Check business state
and tool authorization separately: backend policy enforces permissions and
explicit confirmation for every action.
